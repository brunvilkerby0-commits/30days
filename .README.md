# 30Days Investment Bot

🚀 Telegram investment bot with Firebase, Moralis & TronGrid integration

## Features

✅ Automated profit calculation
✅ BEP20 & TRC20 deposit tracking
✅ Real-time balance updates
✅ Referral system with commissions
✅ Daily attendance tracking
✅ Firebase real-time database
✅ 30-day investment plans

## Installation

### Prerequisites
- Node.js >= 16.0.0
- npm >= 8.0.0
- Git

### Setup

```bash
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/30days-investment-bot.git
cd 30days-investment-bot

# 2. Install dependencies
npm install

# 3. Configure environment variables
cp .env.example .env

# 4. Edit .env and add your API keys:
# - TELEGRAM_BOT_TOKEN
# - Firebase credentials
# - Moralis API Key
# - TronGrid API Key
# - Wallet addresses

# 5. Start the bot
npm start
